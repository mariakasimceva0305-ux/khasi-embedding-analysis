# Порядок слов и зависимости в эмбеддингах кхаси

Диагностика последовательностей слов с фиксированными 32-мерными CBOW-векторами. Проверяется, отличаются ли исходный порядок и временная асимметрия от контрольных последовательностей.

## Протокол

Из 770 пригодных текстов детерминированно по хешу выбраны 40. Для каждого взят самый длинный непрерывный участок известных токенов: от 128 до 512 слов. Неизвестные слова разрывают последовательность.

Соседний cosine similarity сравнивается с 99 перестановками порядка слов. Для второго анализа нормированные векторы проецируются на первую главную компоненту; временная асимметрия сравнивается с 99 IAAFT-суррогатами. Распределение значений сохраняется точно; допустимая относительная ошибка спектра — 5%. Поправка Benjamini–Hochberg применяется ко всем 40 запланированным тестам, включая непрошедшие проверку качества (p=1).

## Результаты

Средняя разница соседнего cosine относительно перемешивания — 0,05479; описательный document-bootstrap интервал 0,04498–0,06433. Локальная совместная встречаемость уже входит в обучение CBOW, поэтому это не независимое доказательство понимания языка.

Порог качества суррогатов прошли 8 из 40 документов. После поправки значимых отклонений временной асимметрии нет. По этому протоколу вопрос остаётся открытым; межъязыковые различия и топологические дыры не установлены.

## Запуск

```text
python analyse.py --archive path/to/khasi_required_final.zip
python -m pytest -q test_surrogates.py
```

Архив должен содержать `raw_texts_by_title/` и `khasi_required_final/4_embeddings/cbow/khasi_cbow_word_vectors_dim32.csv`. Сырые тексты в Git не включены. Параметры — `results/protocol.json`, результаты — `document_results.csv` и `summary.json` внутри `results/`.

Это самостоятельная NumPy-реализация по методике TISEAN, а не запуск TISEAN binary и не восстановление прежнего сравнения с русским и английским. [Описание метода суррогатов](https://www.pks.mpg.de/tisean/TISEAN_2.1/docs/surropaper/node12.html).
